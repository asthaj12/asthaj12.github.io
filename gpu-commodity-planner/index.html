Methodology: Formulas and Limits

Critical ratio CR = Cu ÷ (Cu + Co) GPU: Demand spread σ = (Upside − Downside) ÷ 4 (range rule: span = 4σ) GPU: Optimal commit Q* = μ + σ · Φ⁻¹(CR) GPU:
Correlation matrix R = (1 − ρ)·I + ρ·J (ρ off the diagonal) Cholesky R = L · Lᵀ Correlated draws G ~ N(0, I) from a seeded PRNG (mulberry32, seed 20261105) Z = L · G so corr(Z_i, Z_j) = ρ for every pair Demand D_i = max(0, μ_i + σ_i · Z_i)
Mis-commit cost C = Σ_i [ Cu_i · max(0, D_i − Q_i) + Co_i · max(0, Q_i − D_i) ] ($M per trial) Budget B = 95th percentile of C at ρ = 0, same draws B = Exceedance P(C > B) = #{trials with C > B} ÷ N VaR 95% C at rank ⌈0.95·N⌉ (sorted ascending) CVaR 95% mean of the worst N − ⌊0.95·N⌋ trials of C Mean invariance E[C] = Σ_i E[cost_i(D_i)] depends on each marginal only, so ρ moves the joint tail, not the mean
  • Commit levels come from the independent newsvendor and are held fixed across ρ. A correlation-aware commit would change the tail.
  • One ρ for every pair is a simplification. Real commodity pairs differ in strength.
  • Spot price is shown for reference. Shortfall is costed at Cu, the same underage cost used in the critical ratio, so cost and CR share one set of penalties.
  • Demand is normal with the range rule for σ, truncated at zero. Budget is a planning reference set at the independent 95th percentile, not an approved company budget.
  • All inputs are synthetic.
